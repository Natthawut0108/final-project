# คำนวณค่ารถเมล์ (Bus Fare Calculator)

เว็บประมาณค่าโดยสารรถเมล์กรุงเทพฯ จากต้นทางไปปลายทาง สร้างด้วย Next.js

## วิธีทำงาน
1. ค้นหาต้นทาง/ปลายทางด้วยชื่อสถานที่ (OpenStreetMap Nominatim, `/api/geocode`)
2. หาระยะทางถนนด้วย OSRM (`/api/route`) ถ้าล้มเหลวจะประมาณจากเส้นตรง x 1.3
3. คำนวณค่าโดยสารของรถร้อน / รถแอร์ ขสมก. / รถ EV จาก `lib/fares.js`

## ข้อจำกัด (สำคัญ)
- ราคาเป็น **ค่าประมาณ** จากระยะทาง ไม่ได้อิงสายรถเมล์จริงหรือจำนวนป้าย
- อัตราค่าโดยสารกำลังเปลี่ยน (รถร้อน 8 บาทกำลังทยอยเปลี่ยนเป็น EV) และไม่มีตารางตามระยะทางอย่างเป็นทางการ
  จึงตั้งช่วงราคาจากข่าว: รถร้อน 8 / รถแอร์ 13-25 / EV 15-25 บาท แก้ได้ที่ `lib/fares.js`
- Nominatim และ OSRM เป็นบริการสาธารณะฟรี เหมาะกับโปรเจกต์ขนาดเล็ก ไม่ควรใช้ยิงจำนวนมาก

## รันในเครื่อง
```bash
npm install
npm run dev
```

## Deploy บน Vercel
push ขึ้น GitHub แล้ว Import repo ใน Vercel ได้เลย (ตรวจเป็น Next.js อัตโนมัติ ไม่ต้องตั้งค่า environment variable)
