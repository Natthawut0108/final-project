# บอกสายรถเมล์ + คำนวณค่ารถเมล์ (กรุงเทพฯ)
เว็บหน้าเดียว (HTML ล้วน ไม่ต้อง build) ใส่ต้นทาง-ปลายทางแล้วบอกว่าต้องขึ้นสายไหน (ตรงหรือต่อรถ 1 ครั้ง) พร้อมค่าโดยสารประมาณ

## ไฟล์
- `index.html` ตัวเว็บ + ตรรกะหาสายรถเมล์
- `bus-data.json` ข้อมูลสายและป้ายรถเมล์ ขสมก. (620 เส้นทาง/ทิศ, 4,587 ป้าย) ย่อจากฟีด GTFS ปี 2566 ของ สนข. ผ่าน repo asiripanich/bangkok-gtfs
- `vercel.json` ให้ Vercel deploy เป็นเว็บ static

## วิธีทำงาน
1. ค้นหาสถานที่ด้วย OpenStreetMap Nominatim, ระยะถนนด้วย OSRM
2. หาป้ายใกล้ต้นทาง/ปลายทาง (เดินไม่เกิน 800 ม.) แล้วจับคู่สายที่ผ่านทั้งสองจุดตามลำดับป้าย
3. ถ้าไม่มีสายตรง หาต่อรถ 1 ครั้ง (ป้ายต่อรถห่างกันไม่เกิน 300 ม.)
4. ค่าโดยสารประมาณตามระยะที่นั่งจริงของสายที่แนะนำ (แก้อัตราที่ `BUS_TYPES` ใน `index.html`)

## ข้อจำกัด
- ข้อมูลสายเป็นปี 2566 อาจไม่ตรงปัจจุบัน และไม่มีเวลาเดินรถ/รอบรถ
- ไม่รวมรถร่วมเอกชน รถตู้ และรถไฟฟ้า
- ราคาเป็นค่าประมาณ ไม่ใช่ราคาจริงของแต่ละสาย
